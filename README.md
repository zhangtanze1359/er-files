# er-files

扼守回憶资源站的文件下载仓库。

## 如何上传文件

1. 打开本仓库页面，点击 **Add file → Upload files**
2. 将文件拖入上传区域（单文件建议不超过 100MB）
3. 点击 **Commit changes** 提交

## 如何提供下载

文件提交后，可通过以下地址直接下载：

- Raw 链接：`https://raw.githubusercontent.com/zhangtanze1359/er-files/main/<文件名>`
- jsDelivr CDN：`https://cdn.jsdelivr.net/gh/zhangtanze1359/er-files@main/<文件名>`（国内访问更快）

## 说明

- 仓库公开，任何访客都可直接下载其中的文件
- 免费配额约 1GB，请勿上传版权受限内容
